# Demo assets

`demo.gif`/`demo.png` and `demo-ascii.gif`/`demo-ascii.png` were generated by
`examples/generate_test_video.py` and captured from the real CLI using
`examples/capture_demo.py`. They depict original geometric animation and text.
They are covered by this repository's MIT license. No Chiikawa footage, artwork,
original audio or song lyrics are included. The temporary MP4 is not committed.
